# Soy Ağacı iOS (yerel SwiftUI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web v7.0.0'daki her özelliği içeren, web/Android ile aynı Supabase verisini okuyup yazan yerel SwiftUI iPhone uygulaması.

**Architecture:** Mantık yalnız-Foundation `SoyCekirdek` paketinde, web fonksiyonlarının birebir Swift karşılığı olarak; her modül, web kodunun Node'da çalıştırılmasıyla üretilen fixture'larla Linux CI'da (`swift test`) eşlik testinden geçer. SwiftUI uygulaması (`SoyAgaci/`) çekirdeği kullanır; Supabase (supabase-swift), GoogleSignIn, Apple ile Giriş, PDFKit, MapKit, UserNotifications. Xcode projesi XcodeGen ile bulut Mac'te üretilir, fastlane ile TestFlight.

**Tech Stack:** Swift 5 dil kipi, iOS 17, SwiftUI, SwiftPM, XcodeGen, fastlane, GitHub Actions (Linux `swift:6.0` + macOS), Node 26 (fixture üretimi), Deno (Edge Function).

**Spec:** `docs/superpowers/specs/2026-11-18-ios-yerel-design.md` (okumadan başlama). Web kaynağı: `soy-agaci.html` (v7.0.0; ana betik satır 933–4095).
